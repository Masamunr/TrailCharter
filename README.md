# TrailCharter

Privacy-first, offline-first, open-source Android adventure planning application.

Current phase: **Product Design + Foundation Development**.

Current product name: **TrailCharter — AGREE**.

Current geographic scope: **United Kingdom only** — England, Scotland, Wales and Northern Ireland.

Core architecture: device-resident and local-first, with **no TrailCharter-owned or administered server required for core functionality**.

Live location sharing is outside the current product/release scope.

Repository: **`Masamunr/TrailCharter` — public**.

The first Android foundation is implemented on `main` and CI-verified with unit tests, lint and debug assembly. The current in-app foundation screen is intentionally provisional while the Adventure information architecture and wider visual language remain under design.
