# Altrove Constitution

## Core Principles
- User Ownership
- Privacy First
- Offline First wherever technically practical
- Transparent by Design
- No Dark Patterns
- Simple by Default
- Iterative Development
- Quality Before Quantity

## Status terminology
- **EXPLORE**: investigate, no commitment.
- **AGREE**: current agreed direction; record in specification.
- **FINAL**: deliberately locked; reopen only explicitly.

`SPEC.md` records what is agreed. `PROJECT_STATUS.md` records what actually exists.
