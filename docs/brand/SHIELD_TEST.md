# TrailCharter shield launcher test

Status: EXPLORE / active physical-device test.

The landscape composition remains FINAL. The launcher container decision is temporarily reopened for Android compatibility testing.

Version 0.1.4-foundation uses the previously approved shield treatment from the supplied launcher reference. The shield contains the same approved mountains / trees / river / sun composition without redraw or reinterpretation. The shield is centred on the dark green brand field so Android can apply circle, square and rounded-square adaptive masks to the surrounding field instead of cropping the landscape itself.

Acceptance requires physical-device confirmation that the shield is fully visible, proportioned like the approved reference and free from duplicate layers, edge artefacts or awkward mask cropping.
